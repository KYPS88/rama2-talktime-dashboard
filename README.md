# rama2-talktime-dashboard

แดชบอร์ดสาขา RAMA2 — ส่วนหนึ่งของเว็บรวม **Talktime Center**
(หน้าแรกเปรียบเทียบ 2 สาขาอยู่ที่ [`hq-talktime-dashboard`](https://github.com/KYPS88/hq-talktime-dashboard))

- `index.html` — แดชบอร์ด RAMA2 (auto จาก `rama2-talktime-scripts` ทุกชั่วโมง)
- `payload.json` — ข้อมูล KPI ที่หน้าแรกของเว็บรวมดึงไปแสดง (auto)
